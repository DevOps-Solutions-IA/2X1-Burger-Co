# Engineering Rules

## Reglas obligatorias

- Nunca implementar codigo temporal.
- Prohibidos los hacks y bypasses.
- Prohibido introducir `TODO` o `FIXME` como sustituto de una solucion.
- Prohibidas las soluciones parciales presentadas como cierre completo.
- Prohibido romper otros modulos para cerrar el modulo actual.
- Prohibido inventar datos, evidencia, estados o metricas.
- Prohibido ocultar warnings, errores o fallos de runtime.
- Prohibido declarar GO solo por compilacion.
- Prohibido ejecutar acciones destructivas sin un gate explicito.
- Siempre diagnosticar y demostrar causa raiz antes de corregir.
- Siempre validar typecheck y build cuando aplique.
- Siempre validar integracion y regresion cuando aplique.
- Siempre validar UI y runtime cuando el cambio sea visible u operacional.
- Siempre documentar evidencia, riesgos residuales y rollback.
- Siempre preservar seguridad, auditabilidad e integridad de datos.
- Siempre mantener cambios pequenos, trazables y revisables por dominio.
